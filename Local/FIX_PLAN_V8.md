# v1.13.0 第八轮修复方案

## 核心策略：不降级视觉，只优化性能；根因修复，不打补丁

### 修复1：删除功能增强诊断（不改逻辑，增强反馈）

当前设计已经是正确的（标记删除设计），但需要增强错误反馈：

1. 在 MainActivity.uninstallInstance 中添加更详细的异常日志
2. 在 TarvenEnvPlugin.uninstallInstance 中确保所有错误路径都正确 reject
3. 在前端 DeleteConfirmDialog 中更清晰地展示错误信息
4. 添加"重试删除"功能（针对标记文件已存在的情况）

### 修复2：性能优化（保持视觉效果）

#### 2.1 前端渲染优化
- 使用 CSS contain 属性隔离重绘区域
- 为毛玻璃元素添加 will-change（仅在动画时）
- 使用 transform: translateZ(0) 强制 GPU 加速
- 动画期间暂时降低毛玻璃采样（已有data-sc-ime-anim机制，扩展到所有动画）

#### 2.2 创建/启动性能优化
- 在依赖解压过程中添加性能埋点
- 优化文件IO（减少fsync调用）
- 延迟非关键资源加载

#### 2.3 键盘避让最终优化
- 使用 CSS contain: layout 隔离键盘区域
- 确保动画完全由GPU处理

### 修复3：代码清洗
- 移除无用的残留代码
- 统一错误处理模式
- 确保所有文件保存路径逻辑正确落实

## 实施顺序
1. 先修复删除诊断（最高优先级）
2. 然后优化性能
3. 最后清洗代码
